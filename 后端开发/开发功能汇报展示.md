## 一、项目概述

### 1.1 项目背景

本项目旨在构建一个基于知识图谱的金融实体关系抽取与分析平台，通过对财经新闻进行智能分析，自动识别公司实体间的关系，辅助金融分析师快速了解企业关联网络，支持投资决策与风险分析。

## 二、核心功能实现

### 2.1 新闻关系提取功能

#### 功能定位

基于本地大语言模型（Ollama Qwen3.6 27B），从财经新闻中自动识别两家公司之间的关系，并将提取结果持久化存储到知识图谱数据集。

#### 技术架构

```

│  └────────┬────────┘  └────────┬────────┘  └──────┬──────┘ │
```

| 分类 | 关系类型 |

```python
class RelationExtractor:
    def __init__(self, dataset_path: str = None, use_ollama: bool = True, ollama_model: str = "qwen3.6:27b"):
        """初始化关系抽取器，支持Ollama本地模型"""
        self.use_ollama = use_ollama
        self.ollama_model = ollama_model
        self.ollama_url = "http://localhost:11434/api/generate"
        
    def determine_relation(self, text: str, company1: str, company2: str) -> str:
        """判定两家公司之间的关系类型"""
        if self.use_ollama:
            return self._determine_relation_with_ollama(text, company1, company2)
        else:
            return self._determine_relation_with_keywords(text)
            
    def _call_ollama(self, prompt: str) -> str:

        payload = {
            "model": self.ollama_model,
            "prompt": prompt,
            "stream": False,
            "options": {"temperature": 0.1, "max_tokens": 50}
        }
```

### 2.2 跨文档实体关系抽取功能

#### 功能定位

从大规模财经新闻数据中自动识别两家公司之间的关系，提供端到端的关系抽取与分析能力。

#### 数据处理流程

```
原始新闻 (20,000条)
    ↓
第一层：同句共现检测
    ↓ 过滤掉 88% 的假关系
候选关系 (约 1,600 条)
    ↓
第二层：关系关键词匹配
    ↓ 标注具体关系类型
确定关系 (322 条)
    ↓
第三层：证据句提取
    ↓ 保留判定依据
最终数据集 (180家公司间的关系)
```

#### 数据质量优化

| 数据状态 | 关系条数 | 说明 |
|----------|----------|------|
| 原始标记 | 3,044 条 | 仅表示两家公司在同一篇新闻中出现 |
| 真实关系 | 约 320 条 | 经过滤后确认有实际语义关联 |

**典型误判案例**:
- 《重大事项公告汇总》类新闻，将十几家无关联公司并列在一起
- 《上市公司股价波动快报》类新闻，按涨跌幅排名，公司间并无关系

#### 关系精准化处理

针对214条模糊的"同事件提及"关系，设计了**31条优先级规则**进行精准化分类：

| 优先级 | 关系类型 | 判断依据 |
|--------|----------|----------|
| 1 | 高管履历关联 | "就职于/曾任/兼任" + "董事/高管/独立董事" |
| 2 | 法律纠纷 | "仲裁/诉讼/索赔" + "原告/被告/申请人" |
| 3-8 | IPO审核状态 | 标题含"IPO周报/上会/过会/暂缓" + 内容状态关键词 |
| 9 | 监管处罚名单 | "被点名/飞检/通报批评/行政处罚" |
| 10 | 诚信评级关联 | "红黑榜/诚信/黑名单" |
| 11 | 行业排名/榜单 | 标题含"百强/排名/表彰" |
| ... | ... | ... |
| 31 | 同事件提及 | 无法归入以上任何类型（最终兜底） |

#### 精准化前后对比

| 指标 | 精准化前 | 精准化后 | 变化 |
|------|----------|----------|------|
| 关系类型数 | 10种 | **35种** | +250% |
| 模糊关系占比 | 66%（214/322） | **1.9%**（6/322） | ↓64.1% |
| 可解释性 | 低（仅知"有关"） | **高**（直接反映业务语义） | 显著提升 |

| 关系类型 | 数量 | 占比 | 说明 |
|----------|------|------|------|
| 列举式并列提及 | 35 | 16.4% | 在行业名单、表彰名单中并列出现 |
| IPO中止 | 28 | 13.1% | 因共同原因IPO中止 |
| 监管处罚名单 | 20 | 9.3% | 同被监管点名或处罚 |
| IPO暂缓 | 16 | 7.5% | IPO审核暂缓表决 |
| 业绩对比 | 16 | 7.5% | 在业绩分析中并列对比 |
| 行业对比分析 | 12 | 5.6% | 作为同行业可比公司被对比 |
| 环保履约关联 | 12 | 5.6% | 同一环保名单（碳排放、排污等） |
| 高管履历关联 | 8 | 3.7% | 高管曾在对方公司任职 |
| IPO申报关联 | 8 | 3.7% | 同批IPO申报/上会 |
| ... | ... | ... | ... |
| 同事件提及 | 6 | 2.8% | 无法进一步细分 |

## 七、使用示例

### 7.1 Python SDK调用

```python
from knowledgegraph.relation_extractor import RelationExtractor

# 初始化抽取器（使用Ollama）
extractor = RelationExtractor(
    use_ollama=True,
    ollama_model="qwen3.6:27b"
)

# 新闻数据
news = {
    "title": "新闻标题",
    "source": "来源",
    "time": "2025-12-03",
    "url": "https://example.com/news",
    "abstract": "新闻摘要",
    "content": "新闻正文..."
}

# 提取关系
relations = extractor.extract_from_news(news)

# 保存关系
for rel in relations:
    extractor.add_relation(
        company1=rel['company1'],
        company2=rel['company2'],
        relation=rel['relation'],
        evidence=rel['evidence'],
        news=rel['news']
    )
```

## 九、附录：核心关系类型定义

| 关系类型 | 定义 | 示例 |
|----------|------|------|
| 保荐/承销 | 证券公司担任企业IPO或再融资的保荐机构 | 国元证券保荐安徽金种子酒业 |
| 投资/收购 | 一家公司对另一家公司的股权收购或战略投资 | A公司收购B公司51%股权 |
| 子公司/控股 | 母公司与子公司之间的控制关系 | A公司持有B公司60%股权 |
| 起诉 | 公司之间的法律诉讼关系 | A公司起诉B公司专利侵权 |
| 合作 | 公司之间的业务合作关系 | A公司与B公司签署战略合作协议 |
| 供应/采购 | 供应链上下游关系 | A公司是B公司的主要供应商 |
| IPO中止 | 因共同原因IPO申请被中止 | A公司与B公司同批IPO中止 |
| 监管处罚名单 | 同时被监管机构点名或处罚 | A公司与B公司同入飞检名单 |
| 高管履历关联 | 高管曾在对方公司任职 | A公司CEO曾任B公司副总裁 |
