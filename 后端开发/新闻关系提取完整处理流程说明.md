### 2.2 文件读取与解析

**函数**: `handleFileUpload(file)`

**步骤1: 读取文件内容**
```javascript
const fileContent = await this.readFile(file.raw);
```

**步骤2: 根据文件类型构造newsData**

| 文件类型 | 处理方式 | 字段构造 |
|----------|----------|----------|
| `.json` | `JSON.parse(fileContent)` | 直接使用JSON字段 |
| `.md/.txt` | 文本解析 | 按规则构造字段 |

**Markdown/文本文件的字段构造规则**:
```javascript
newsData = {
  title: file.name.replace(/\.[^/.]+$/, ""),           // 文件名作为标题
  source: "上传导入文件",                              // 固定来源
  time: new Date().toISOString().split('T')[0],        // 当前日期
  url: "",                                             // 空URL
  abstract: fileContent.substring(0, 200) + "...",     // 前200字作为摘要
  content: fileContent                                 // 完整内容
}
```

### 2.3 字段验证与补齐

**验证规则**: 确保6个必要字段存在
```javascript
const required_fields = ['title', 'source', 'time', 'url', 'abstract', 'content'];
for (const field of required_fields) {
    if (!(field in newsData)) {
        newsData[field] = "";
    }
}
if (!newsData.title) newsData.title = "未知标题";
```

**请求配置**:

### 3.2 关系抽取核心处理

**调用**: `extractor.extract_from_news(news)`

**文件**: `knowledgegraph/knowledgegraph/relation_extractor.py`

**类**: `RelationExtractor`

#### 步骤1: 合并完整文本
```python
full_text = f"{news.get('title', '')} {news.get('abstract', '')} {news.get('content', '')}"
```

#### 步骤2: 提取公司实体
**方法**: `extract_companies(full_text)`

```python
def extract_companies(self, text: str) -> List[str]:
    found_companies = []
    for company in self.companies:  # 从预定义的公司列表匹配
        if company in text:
            found_companies.append(company)
    return list(set(found_companies))
```

**示例**: 
- 输入文本包含"国元证券股份有限公司"和"安徽金种子酒业股份有限公司"
- 输出: `['国元证券股份有限公司', '安徽金种子酒业股份有限公司']`

#### 步骤3: 两两组合判定关系
```python
results = []
for i, company1 in enumerate(found_companies):
    for j, company2 in enumerate(found_companies):
        if i != j:  # 避免自己和自己组合
            relation_type = self.determine_relation(full_text, company1, company2)
            evidence = self.extract_evidence(full_text, company1, company2)
            
            results.append({
                "company1": company1,
                "company2": company2,
                "relation": relation_type,
                "evidence": evidence,
                "news": news
            })
```

**组合逻辑**: 如果有N家公司，会产生 N × (N-1) 条关系
- 2家公司 → 2条关系 (A→B, B→A)
- 3家公司 → 6条关系

#### 步骤4: 关系类型判定

**方法**: `determine_relation(full_text, company1, company2)`

**双模式设计**:

**模式A: Ollama LLM判定** (首选)
```python
def _determine_relation_with_ollama(self, text: str, company1: str, company2: str) -> str:
    relation_types_str = "\n".join([f"- {rt}" for rt in self.relation_types])
    
    prompt = f"""
    请分析以下新闻文本中两家公司之间的关系，并从给定的关系类型列表中选择最合适的一个。

    新闻文本：
    {text[:1000]}...

    公司A：{company1}
    公司B：{company2}

    关系类型列表：
    {relation_types_str}

    请只返回关系类型名称，不要添加其他解释。
    """
    
    result = self._call_ollama(prompt)
    
    if result and result in self.relation_types:
        return result
    else:
        return self._determine_relation_with_keywords(text)  # 备选
```

**Ollama调用**:
```python
def _call_ollama(self, prompt: str) -> str:
    payload = {
        "model": "qwen3.6:27b",

        "stream": False,
        "options": {
            "temperature": 0.1,
            "max_tokens": 50
        }
    }
    
    response = requests.post(
        "http://localhost:11434/api/generate", 
        json=payload, 
        timeout=120
    )
    return result.get('response', '').strip()
```

#### 步骤5: 证据句提取

**方法**: `extract_evidence(full_text, company1, company2)`

```python
def extract_evidence(self, text: str, company1: str, company2: str) -> str:
    # 按句子分割
    sentences = re.split(r'[。！？；]', text)
    
    # 查找同时包含两家公司名的句子
    for sentence in sentences:
        if company1 in sentence and company2 in sentence:
            return sentence.strip()
    
    # 如果没找到，返回前200字
    return text[:200] + "..." if len(text) > 200 else text
```

**示例**:
- 原文: "国元证券股份有限公司（以下简称"国元证券"或"保荐机构"）作为安徽金种子酒业股份有限公司（以下简称"金种子酒"或"公司"）非公开发行股票的保荐机构..."
- 输出: 该句子作为证据句

### 3.3 数据持久化

**方法**: `add_relation(company1, company2, relation, evidence, news)`

```python
def add_relation(self, company1: str, company2: str, relation: str, evidence: str, news: Dict):
    # 1. 初始化公司1的关系字典
    if company1 not in self.relations:
        self.relations[company1] = {}
    
    # 2. 添加关系 (如果不存在)
    if company2 not in self.relations[company1]:
        self.relations[company1][company2] = {
            "relation": relation,
            "evidence": evidence,
            "news": news
        }
    
    # 3. 保存到JSON文件
    self._save_dataset()
```

## 六、关键处理逻辑总结

### 6.1 数据处理管道

| 步骤 | 输入 | 处理 | 输出 |
|------|------|------|------|
| 1.文件读取 | test.md | FileReader | 文本字符串 |
| 2.字段构造 | 文本 | 提取前200字为摘要 | newsData对象 |
| 3.实体识别 | newsData | 字符串匹配 | 公司列表 |
| 4.关系判定 | 公司+文本 | Ollama/关键词 | 关系类型 |
| 5.证据提取 | 文本+公司 | 句子匹配 | 证据句 |
| 6.数据存储 | 关系对象 | JSON序列化 | 数据集文件 |

### 6.2 智能判定逻辑

```
文本输入
   │
   ├─> Ollama LLM (qwen3.6:27b)
   │   ├─> 成功 ──> 返回关系类型
   │   └─> 失败/超时 ──> 备选方案
   │
   └─> 关键词匹配
       ├─> 匹配到关键词 ──> 返回对应关系类型
       └─> 无匹配 ──> "同事件提及"
```

### 6.3 数据流向
