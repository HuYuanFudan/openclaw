## 七、可能存在的后续问题

### 7.1 CORS跨域问题

**风险描述**: 前端运行在 `localhost:8080`，后端API在 `10.176.22.62:8001`，浏览器可能阻止跨域请求。

**解决方案**:
1. **方案A**: 配置Django CORS中间件
   ```python
   # settings.py
   CORS_ALLOWED_ORIGINS = [
       "http://localhost:8080",
   ]
   ```

2. **方案B**: Vue配置代理 (推荐)
   ```javascript
   // vue.config.js
   module.exports = {
     devServer: {
       proxy: {
         '/api': {
           target: 'http://10.176.22.62:8001',
           changeOrigin: true
         }
       }
     }
   }
   ```

### 7.2 Ollama超时问题

**风险描述**: 模型推理偶尔超时(120秒)

**解决方案**:
- 增加超时时间
- 使用更小的模型作为备选
- 优化提示词减少token数

## 八、总结

### 8.1 问题根因

1. 前端代码中硬编码了错误的API地址 `127.0.0.1:8080`
2. `8080` 是Vue开发服务器端口，不是后端API端口
3. 后端Django服务实际运行在 `8001` 端口

### 8.2 修复措施

将 `front/src/views/CrossDocEntityExtract.vue` 中的 `extract_relation` API地址修改为正确的后端地址：
```
http://10.176.22.62:8001/extract_relation/
```

### 8.3 验证结果

- ✅ 后端API测试通过
- ✅ 成功提取公司实体关系
- ✅ 数据正确保存到数据集

### 8.4 建议

1. 统一项目中所有API调用的基础URL配置
2. 建议使用环境变量管理API地址
